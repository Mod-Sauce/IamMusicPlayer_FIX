IMPR Dev Textures - Development Texture Pack
=============================================

This is a built-in resource pack for Iam Music Player Renewed that contains
placeholder textures for development and customization purposes.

HOW TO USE:
-----------
1. Launch Minecraft with the mod installed
2. Go to Options > Resource Packs
3. Find "IMPR Dev Textures" in the available packs
4. Click the arrow to move it to "Selected Resource Packs"
5. Click "Done" to apply

CUSTOMIZATION:
--------------
All textures in this pack are placeholders copied from the mod's default textures.
You can modify these textures to create custom appearances for:

- Blocks (boombox, cassette deck, music manager)
- Items (cassette tapes, antennas, manual)
- GUI elements
- Entity textures

The texture files are organized in the following structure:
- assets/iammusicplayer/textures/block/
- assets/iammusicplayer/textures/item/
- assets/iammusicplayer/textures/gui/
- assets/iammusicplayer/textures/entity/

NOTES:
------
- This pack uses pack format 15 (Minecraft 1.20.1)
- All textures are PNG format
- Modify textures while the game is running and use F3+T to reload resources
- Keep backups of your custom textures before updating the mod

For more information, visit: https://mod-sauce.github.io/impr.html
